Class I is breach-notifiable information: SSNs, payment card data, protected health information, government IDs, and credential combinations. No tool below is self-service for Class I. Appearing in these results means only that a Lehigh agreement can cover Class I in principle — it does not approve your use case. Information Security must review each Class I workflow individually before any Class I data is entered into an AI tool, without exception.

How the match score works. Each tool carries a capability profile per use case (0 to 100), blended with a data-handling fitness factor. Scores reflect the model tier and features in Lehigh's licensed configuration, not the vendor's frontier offering. Inventory and scores are maintained by the Information Security office and reviewed quarterly. Community feedback informs those reviews but never changes a published score automatically. Availability is determined by current Lehigh licensing, not by the tool's quality. Anything not already provisioned can be requested through the AI tool request form, which covers both departmental purchases and the enhanced access funded by the H.S.
